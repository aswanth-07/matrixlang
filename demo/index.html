Python disagrees with itself

Each pair below computes the same value two ways, evaluated by Python on this machine: in a different order, or after a rewrite a compiler would like to make. Every result is drawn as its 64 bits; the bits that differ are drawn white.

    So compilers either refuse to reorder floating-point arithmetic, and leave the speed on the table, or reorder blindly under -ffast-math and change the answer without saying so. MatrixLang proves, for each rewrite, which of these bits it keeps.

    Language reference

    matrix A[40,2] = input(int8); declares an input; the compiler sees only its domain. Domains: bool uint8 int8 int16 int32 int(lo,hi) real real(B) real(lo,hi).

    A * B is a matrix product, 2 * A a scaling, u * transpose(v) a dot product. Also + - transpose() identity(n) zeros(r,c) ones(r,c) and literals {{1,2},{3,4}}.
