Language reference

            
matrix A[2,3]; declares a zero matrix. matrix C = A * B; infers its shape.

            
Construct values with {{1,2},{3,4}}, zeros(r,c), ones(r,c) and identity(n). Use transpose(A) and print(A).

            
matrix A[40,2] = input(int8); declares a run-time input. Domains: bool, uint8, int8, uint16, int16, int32, int(lo,hi), real, real(B), real(lo,hi). The optimizer sees only the domain; values are checked against it before execution.

            
Products require matching inner dimensions. Addition and subtraction require equal shapes. Dimensions are static; the language has no loops or functions.
