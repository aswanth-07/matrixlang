# Security and supported scope

MatrixLang is an educational command-line compiler and static demonstration.
It is not a sandbox for hostile programs or a production numerical service.

For a suspected vulnerability, use GitHub's private reporting facility if it is
available on this repository's Security tab. Avoid putting credentials or other
private data in a public issue. Ordinary compiler correctness bugs can be reported
with a minimal program and the relevant command, toolchain and output.

No response deadline, supported-version guarantee or security certification is
promised. The compiler's tests characterize the documented artifact behavior.
