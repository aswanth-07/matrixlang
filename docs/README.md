# MatrixLang documentation

Which document answers which question.

| Document | Read it for |
| --- | --- |
| [language-reference.md](language-reference.md) | What the language *is*: tokens, grammar, shape rules, every diagnostic, the VM instruction set. The definition `matrixc` is checked against. |
| [design.md](design.md) | Why the code is shaped the way it is. Decisions, trade-offs, and the bugs worth remembering. |
| [phase1-design.md](phase1-design.md) | Review 1 deliverable: title, abstract, problem statement, motivation, objectives, scope, background study, architecture, technology stack, prototype. |
| [phase2-implementation.md](phase2-implementation.md) | Review 2 deliverable: each frontend module, what it does, and its real output. |
| [phase3-optimization.md](phase3-optimization.md) | Review 3 deliverable: the optimizer passes, measured results, target code, the VM, testing and limitations. |
| [REPORT.md](REPORT.md) | The final project report, in the eleven-chapter structure the lab manual specifies. Cross-references the three phase documents rather than repeating them. |

## Directories

| Path | Contents |
| --- | --- |
| `figures/` | Generated figures. `architecture.png` is built by `tools/build-architecture-figure.py` and embedded in both the report and the submission document. |
| `submission/` | Deliverables in the format the department accepts. `MatrixLang-Phase1.docx` is generated by `tools/build-phase1-docx.js`; `MatrixLang-Deck.pptx` by `tools/build-deck.py`. |

Both are regenerable. They are committed anyway because a submission deadline is
a poor time to discover that a generator needs a toolchain you no longer have.

## Regenerating

```bash
python tools/build-architecture-figure.py docs/figures/architecture.png
node   tools/build-phase1-docx.js          docs/submission/MatrixLang-Phase1.docx
python tools/build-deck.py                 docs/submission/MatrixLang-Deck.pptx
```

The figure script needs Pillow; the document script needs the `docx` npm
package; the deck script needs only the Python standard library.
